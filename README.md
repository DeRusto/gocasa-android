# GoCasa Android

A kiosk app for [GoCasa](https://github.com/DeRusto/goCasa) wall displays on LineageOS tablets and Chromebooks: a full-screen WebView on your GoCasa server that keeps the screen on natively, so the Wall display stays awake without HTTPS.

Not built yet. See the plan in [GoCasa's research note](https://github.com/DeRusto/goCasa/blob/main/docs/research/home-assistant-and-android.md#21-option-a-webview-kiosk-shell-recommended).
